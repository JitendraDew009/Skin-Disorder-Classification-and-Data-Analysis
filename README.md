# Skin Disorder Classification and Data Analysis

This project explores a dermatology dataset to classify skin disorders using machine-learning models in a Jupyter notebook.

## Files
- `PRCP-1027_Skin_Disorder_Analysis.ipynb` — full analysis, preprocessing, model comparison, and evaluation
- `dataset_35_dermatology (1).csv` — dataset used for training and testing

## Goal
Understand the dataset, compare classifiers, and summarize the potential of automated skin disorder prediction.

## Final insights
- This is a learning/research project and not a medical diagnosis tool.
- The dataset is small but structured, with clinical and histopathological features for multi-class classification.
- Proper preprocessing and validation are essential before drawing conclusions from model results.
- For real-world clinical use, a larger dataset and expert medical review would be necessary.
