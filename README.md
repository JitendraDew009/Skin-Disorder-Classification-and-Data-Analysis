# Skin Disorder Classification and Data Analysis

This project focuses on classifying skin disorders using machine learning techniques on a dermatology dataset. It explores how medical features can be used to predict disease categories in a structured and reproducible way.

## Problem
Skin disorders often require expert evaluation and time-consuming manual diagnosis. In many cases, clinical signs and histopathological features are difficult to interpret consistently without specialist support. This makes early and accurate classification challenging, especially when large datasets need to be analyzed efficiently.

## Solution
This project uses a machine learning approach to analyze labeled dermatology data and classify skin disorders based on relevant features such as clinical symptoms and histopathological indicators. The notebook loads the dataset, preprocesses it, compares multiple classifiers, and evaluates model performance to identify the most suitable approach for this problem.

## Project Overview
The repository contains:
- `PRCP-1027_Skin_Disorder_Analysis.ipynb` — full analysis, preprocessing, model comparison, and evaluation
- `dataset_35_dermatology (1).csv` — dataset used for training and testing

## Goal
To study the dataset, compare predictive models, and assess how machine learning can support skin disorder classification in a research context.

## Final Insights
- This project demonstrates a data-driven approach for classifying skin disorders.
- The dataset is suitable for a supervised learning experiment using clinical and histopathological features.
- Model performance depends strongly on preprocessing, validation, and the quality of the dataset.
- This is a research/learning project and is not a medical diagnosis system.
- For real-world clinical use, a larger dataset, expert validation, and medical review would be required.
